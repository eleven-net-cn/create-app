# 核心特性

`create-app` 是一个专为现代 Web 开发设计的强大脚手架工具，提供了丰富的功能和灵活的配置选项。

## ⚡ 模板开发支持热更新

create-app 仓库中模板开发支持一键启动、热更新调试。

## 🎨 模板包自由组合

模板包之间可相互调用、组合，最大限度提升可复用性。

## 🔄 混合模式支持

可以向现有项目添加配置，方便在旧项目中迅速集成某些工具

```bash
# 向现有项目添加开发工具配置
npx @e.fe/create-app@latest -T @e.fe/template-standard --mixin

# 使用本地模板包
npx @e.fe/create-app@latest -T file:./my-template --mixin
```

## 🚀 内存组装，一次性写入

所有模板在内存中组装完成后再写入磁盘，提升模板渲染速度，同时，这也是为模板开发的热更新而设计。

## 🛠️ 灵活的渲染引擎

基于 EJS 的强大模板引擎，支持动态内容生成：

- **文本文件 EJS 处理**：所有文本文件都会经过 EJS 处理，支持动态内容生成
- **条件渲染**：根据用户选择动态生成内容
- **变量注入**：自动注入项目名称、作者等信息
- **文件重命名**：支持动态文件名生成（`_` → `.`）
- **智能合并**：自动合并 package.json 等配置文件

## 📦 丰富的模板包生态

基于独立的 npm 包系统，每个模板都是可独立发布和维护

- **官方模板包**：提供常用的项目模板和配置
- **第三方模板包**：支持使用社区贡献的模板
- **本地模板包**：支持使用本地开发的模板
- **GitHub 模板包**：支持直接从 GitHub 仓库使用模板
